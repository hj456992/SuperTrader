## 实现范围

生产改动仅为 `RanchAnalyzer.java`、新增 `StrategyRuntime.java` 和 `web/src/ranch-view.js`。攻略仍直接调用 ModelRegistry，保留双方材料、自述、对象画像、目标／情境和书籍检索；不要求本人画像。没有修改画像 Agent、检索算法、来源、数据库布局、公共底座或依赖。

- 首次调用加至多一次结构／引用修复，共用从 worker 开始计时的 110 秒应用预算；每次整数 maxTokens=6000。
- 取消结束本地异步准备等待，迟到准备结果不建立模型订阅；流取消完成后再发布 cancelled，旧任务不影响新任务。
- 接收过程中限制 50,000 个 UTF-16 文本字符和 20,000 个流事件；超限、超时、传输失败及非正常终态不触发结构修复。
- 真实阶段与模型步骤对应；保存仍经过原有任务身份、revision 和同步屏障。新攻略附加 runId／basedOnRevision，旧记录不回填。
- 前端区分攻略与画像的阶段，已存结果提示按目标及类型判断；中断提示要求核对结果，不把中断直接解释成未保存。
