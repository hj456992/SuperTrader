## 交互回退风险与最小处理

| 风险 | 可见后果 / 限制 | 本批处理 |
| --- | --- | --- |

| 旧终态提示和未提交输入 | 本地隐藏记录与草稿不跨页面重开持久化 | 不把重开视为自动恢复工作；不扩展存储或记忆功能 |
| 用户材料触发不同业务组合 | 实际内容或模型质量问题未必在静态检查暴露 | 不使用用户聊天做夹具，另由产品收敛匿名/虚构复现场景后安排 |

| token 流式、推荐问题、跨会话记忆 | 保持待决定；不添加入口、占位按钮、伪流式或自动调用 | 必须单独确认用户问题、成本、取消与保存语义、范围；当前未知项不等于推荐问题，持久画像不等于会话记忆 |
