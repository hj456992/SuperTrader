# 专家生产：概要审核设计与原型

本轮只展开管理员对整本书概要的审核。概要通过后进入“待审子专家”，不会直接完成团队。

| 产物 | 用途 |
| --- | --- |
| [管理员页面原型](prototype/index.html) | 体验查看概要、聊天反馈、改稿、确认及刷新恢复 |
| [状态流转](summary-review-state.md) | 定义每一步的触发、校验、保存与恢复 |
| [数据库草案](schema.sql) | 将既有15张逻辑表细化为建表SQL，未迁移业务数据 |
| [接口合同](api-contract.md) | 定义概要审核第一闭环的请求、结果、冲突和事件补读 |
| [验收记录](verification.md) | 实际检查证据与未覆盖范围 |

原型使用演示概要和来源占位，不代表重新研读过用户上传的整本书。页面中的识别、改稿和保存均为演示；生产设计以数据库状态、模型处理和服务端校验为准。此次没有接入真实模型、部署数据库/Redis、修改真实专家或发布新版本。

[存储职责与15表设计理由](storage-design.md)摘录自既有架构第13篇。本目录是可随仓库阅读的交付快照；完整架构源文档继续在原文档目录维护。
