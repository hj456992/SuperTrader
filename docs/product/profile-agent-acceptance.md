## 1. 已核对的现有路径

依据：基线 `web/src/ranch-view.js` 与 `web/src/ranch-ui.js` 的页面、表单、请求及轮询实现；这是源代码核对，未运行浏览器。

| 路径 | 现有操作 | 本轮要求 |
| --- | --- | --- |
| 本人 | 主导航「我的画像」→「我的材料」粘贴本人发言或关联聊天时选择本人身份 →「生成我的画像」；支持编辑自述 | 可汇总各人物材料中标为「我的发言」的内容；排除他人发言作为本人事实；区分自述、聊天、背景与方法 |
| 对象 | 「添加一个人」填写名字，选择「认识朋友 / 发展亲密关系」及可选具体期待 → 对象「了解材料」→「生成画像 · 孵化」 | 只用所选对象的适格材料形成初步画像；备注保留「用户转述」来源；目标用于后续建议 |
| 建议 | 对象「相处攻略」填写可选情境 →「生成相处攻略」 | 继续使用目标画像、双方真实材料、目标和参考资料；不扩展新策略业务、不自动发送 |
| 书架与任务 | 「资料书架」上传、启停、删除资料；当前全局任务提示、轮询和取消 | 画像也可检索书籍；展示实际阶段、引用与限制；关闭页面不代表取消 |

## 2. 验收读法与证据约定

所有材料均须人工虚构。最小素材可以是：本人明确说「我通常提前约时间」；对象甲说「工作日只在晚上方便回复」；甲另一次说「这周午休也能回」；对象乙说「我喜欢临时约」；背景或用户备注说「我猜甲不愿聊天」。书籍片段可以自编「区分回复时段与交往意愿，需结合上下文」，注明为测试方法资料，不能冒充真实作者著作。

下列测试 ID 独立、可追踪。证据类型分为：**确定性**（可控模型/工具替身和断言）、**界面**（渲染或操作记录）、**运行**（实际启动装配、持久化及重启记录）。替身验证不能证明真实模型质量；真实模型运行须单列是否执行、使用链路及观察结果。所有失败、阻塞、未测均如实记录，不用截图或角色自述替代断言。

## 3. 编号 Given / When / Then 验收

### A01 本人画像成功（确定性 + 界面）

- **Given** 本人材料及其他人物材料中有标为「我的发言」的虚构记录，同时含他人发言与背景，启用书籍有相关片段。
- **When** 用户从「我的画像」发起生成，工具返回本人聊天与书籍观察，模型继续生成并通过校验。
- **Then** 保存本人初步画像；直接信息与推断分开，展示覆盖、未知项及实际读取的引用；他人发言、背景和书摘不能变成本人的直接事实；书籍状态为 `used`。

### A02 对象画像成功（确定性 + 界面）

- **Given** 用户选择对象甲并设置交往目标，材料含甲、本人及对象乙的发言，书籍有相关片段。
- **When** 用户在甲的人物空间生成画像。
- **Then** 结果保存给甲且引用归属正确；本人或乙的言论不能作为甲自己的事实；能看到甲的聊天依据、方法参考与有限认识，而不是把用户期望写成人物特征。

### A03 书籍是方法，聊天是人物事实来源（确定性 + 界面）

- **Given** 书籍提出某种沟通解释，但没有目标聊天证据支持该解释。
- **When** 模型尝试把书中观点写成目标的确定特征。
- **Then** 不得以书摘替代人物证据；`knowledgeIds` 与 `evidenceIds` 分开，书籍 ID 不进入人物 `evidenceIds`；可支持的推断仍须限定范围，无法支持的内容保留未知。聊天中的直接事实无需强制附书籍引用。

### A04 目标独立与既有建议兼容（确定性）

- **Given** 人物聊天、书籍、身份保持不变，仅把关系目标从认识朋友改为发展亲密关系。
- **When** 保存目标或在相同受控模型条件下再次生成画像，并随后生成既有相处建议。
- **Then** 保存目标不会重写画像事实；画像生成输入不携带用于改变人格结论的交往目标；不得凭目标新增人格或好感结论。建议路径可使用新目标，仍受事实与边界约束。允许既有待更新标记；不要求真实模型两次输出逐字相同。

### A05 资料不足（确定性 + 界面）

- **Given** 当前主体没有适格聊天，或只有极少材料、只有背景/他人发言。
- **When** 用户发起画像生成。
- **Then** 明确提示资料不足、覆盖有限与未知项；有足够依据的少量内容可形成有限画像，没有可支持内容时明确告知无法生成，不编造完整人格。自述或用户转述不得伪装为聊天事实。

### A06 互相冲突的聊天（确定性 + 界面）

- **Given** 甲的两条虚构测试发言在不同时间或情境下看似冲突。
- **When** 模型读取冲突并可补查上下文。
- **Then** 结果保留冲突或情境限制，展示可用反证/不确定性；不得为迎合目标静默丢弃反证；不能把「这周午休能回」扩写成长期随时可联系。

### A07 没有可用书籍（确定性 + 界面）

- **Given** 没有可检索的启用资料，且人物聊天足够支持有限认识。
- **When** 生成本人或对象画像。
- **Then** 允许基于聊天生成有限画像，`knowledgeStatus=empty_library`，明确提示未使用书籍方法，不伪造书名、书摘或知识引用。

### A08 有书但未命中（确定性 + 界面）

- **Given** 存在启用书籍，但本次检索无相关结果。
- **When** 生成本人或对象画像。
- **Then** `knowledgeStatus=no_match`，提示未找到相关方法；可生成有聊天依据的有限画像；不把「未命中」说成书架为空，也不强行贴无关书摘。

### A09 真实工具循环与观察生效（确定性 + 运行）

- **Given** 本人和对象各有受控测试，模型第一步请求书籍/聊天工具，工具返回可改变初始判断的观察。
- **When** 通过既有 DSH/AgentScope 循环及工具调度器执行。
- **Then** 两条路径均验证书籍检索后模型再次调用；至少一个测试验证两步工具循环中观察确实改变后续输出。只声明工具、直接调用模型或写假循环不能通过；实际装配加载已有 AgentScope 路径另留运行证据。

### A10 转述与身份归属（确定性 + 界面）

- **Given** 用户备注说「我猜甲不愿聊天」，群聊同时有甲与乙的发言。
- **When** 为甲生成画像。
- **Then** 备注始终标为用户转述/推断，不冒充甲说过的话；群聊他人发言只保留其背景角色，不能成为甲的自身事实；界面不把这些来源统一显示为「对方发言」。

### A11 引用只来自实际读取材料（确定性）

- **Given** 模型返回未知 ID、读过别人的 ID、库中存在但本任务未读取的 ID，或把书籍 ID 放进人物证据。
- **When** 输出进入保存前校验。
- **Then** 非法引用不获正式保存；即使 ID 存在于全库也不能绕过任务读取与主体范围。合法引用可回看相应片段和来源，引用失败不得伪报生成成功。

### A12 删除依据后的画像（确定性 + 界面）

- **Given** 当前或历史画像引用某份聊天/书籍材料。
- **When** 用户按现有功能删除该依据，再读取画像。
- **Then** 不再把已删除来源及保留书摘展示为可用依据；相关结果失效、清理或提示重新生成，不能继续显示为有有效依据的最新画像。具体兼容清理方案由实现遵守既有存储规则，不新增档案或回收站功能。

### A13 真实执行阶段（确定性 + 界面）

- **Given** 一个已接受的画像任务正在运行。
- **When** 页面轮询获得 `phase/step/message/events`。
- **Then** 显示实际发生的准备、方法检索、聊天查证、整理、核验或保存阶段；未发生的阶段不补演，未知耗时不编进度百分比。阶段轮询不称为 Token 流；不展示内部推理、凭据、整段聊天或未经校验的模型输出。事件列表有界。

### A14 取消三处竞态（确定性）

- **Given** 分别构造任务提交响应尚未返回、模型/工具执行中、正式保存前的可控时间点。
- **When** 对当前任务请求取消（第一种可用兼容的省略 `runId` 请求），并让旧回调迟到返回。
- **Then** 取消被接受后进入 `cancelling` 或已终止状态，传播到模型与工具；最终取消任务不提交迟到画像、不覆盖已有有效画像。若保存已先完成，应如实保留完成状态，不把已提交任务假称取消成功。

### A15 定向与重复取消（确定性 + 界面）

- **Given** 旧任务 A 已结束，新任务 B 正在运行。
- **When** 重复取消 A，或传入与 B 不匹配的 `runId`；另验证旧客户端省略 `runId`。
- **Then** 定向取消 A 不能误伤 B；重复取消安全；省略 `runId` 仍可取消当前任务。取消期间不允许再次启动冲突任务。

### A16 关闭页面及重开（界面 + 运行）

- **Given** 有已保存画像，或服务未重启且有运行任务。
- **When** 关闭页面后重新打开或刷新。
- **Then** 已保存画像及其有效依据仍可读取；刷新/关闭本身不重新生成、不取消任务；运行任务读取服务中的当前状态。不得承诺浏览器关闭后自动通知等新增功能。

### A17 服务重启中断（运行）

- **Given** 已保存画像存在，同时有未完成任务的最小持久记录。
- **When** 服务重启后重新读取状态。
- **Then** 已保存画像仍可读取；未完成任务为 `interrupted` 并提示重新发起，不声称模型自动续跑，不产生假成功或永久运行提示。

### A18 运行进度与业务修订隔离（确定性）

- **Given** 画像任务在业务修订 R 启动。
- **When** 仅写阶段进度，或在另一个场景中真正修改输入材料。
- **Then** 仅进度变化不能使自己的 R 失效；实际输入变更须在正式保存前校验，旧输入结果不得覆盖最新业务状态。不得以取消修订校验换取成功。

### A19 超预算或超时（确定性 + 界面）

- **Given** 模型持续请求工具或无法在配置时间内完成。
- **When** 达到最多 6 个模型步骤或配置的总时限/工具输出上限。
- **Then** 停止继续消耗，明确失败或已校验的有限结果；不保存半截 JSON，不无限循环；有限结果必须说明限制。110 秒是基线建议时限，不新增精确完成时间承诺。

### A20 模型或工具失败（确定性 + 界面）

- **Given** 模型/工具报错，或输出结构无法通过校验。
- **When** 任务结束。
- **Then** 展示真实错误或明确受限结果；没有有效结果时不覆盖旧画像、不称成功，不泄露凭据/内部异常细节；失败与无书/无命中可区分。

### A21 快速切换人物（确定性 + 界面）

- **Given** 甲任务进行中，随后切换乙或本人页面，旧响应稍后到达。
- **When** 界面渲染任务与画像引用。
- **Then** 不把甲任务、书摘或画像挂到乙/本人名下；全局任务提示如保留须能辨识其归属；取消作用于提示所代表的任务。无需新增多任务并发产品。

### A22 旧数据和接口兼容（确定性 + 界面）

- **Given** 旧画像缺少 `knowledgeStatus/runId/version` 及新增 facet 字段，旧 job 只有兼容字段。
- **When** 展示旧记录，或旧客户端使用既有分析、策略、状态和取消接口。
- **Then** 页面可正常使用，缺省字段不崩溃，也不虚构「使用过书籍」或任务历史；原字段语义及既有接口可用，不要求破坏性迁移。

### A23 内容展示与策略回归（确定性 + 界面）

- **Given** 虚构聊天/书籍/模型文本包含 HTML 特殊字符，且存在有效人物画像及既有策略输入。
- **When** 查看画像、引用并生成相处攻略。
- **Then** 文本安全转义显示；既有建议、行为依据、知识参考和参考回应仍可用；复制参考回应后仍由用户自行发送。

## 4. 最小交互文案

沿用现有按钮与布局；以下是对应状态的最小文案，主体名等变量按现有转义规则处理。没有数据证明的状态不能套用文案。

| 场景 / 字段 | 文案 |
| --- | --- |
| 画像说明 | 「聊天提供人物依据，书籍提供理解方法。初步画像只覆盖已读取材料。」 |
| 目标提示（现有目标表单） | 「交往目标用于相处建议，不改变人物事实。」 |
| 直接信息 / 推断 | 「直接信息」 / 「推测」 |
| 方法与证据区分 | 「聊天依据」 / 「书籍方法参考」；自述仍为「我的自述」，备注仍为「我的备注 · 用户转述」，背景为「上下文 / 背景」 |
| 覆盖与冲突 | 「材料覆盖 {used} / {total}」；「存在不同表达，暂不能确定；请结合时间与情境理解。」 |
| 资料不足 | 「当前材料不足，暂不能形成可靠判断。可补充本人发言或相关上下文。」（对象路径将「本人」替换为「对方」） |
| empty_library | 「当前没有可用的书架资料，本次仅依据聊天形成有限画像。」 |
| no_match | 「未找到相关书籍方法，本次仅依据聊天形成有限画像。」 |
| used | 「本次参考了已读取的书籍片段；书中观点不等于人物事实。」 |
| preparing | 「正在整理所选人物的材料」；本人路径为「正在整理我的材料」 |
| knowledge | 「正在检索参考方法」 |
| evidence | 「正在查找相关聊天依据」 |
| reasoning | 「正在结合已读取材料整理初步画像」 |
| validating | 「正在核验来源与结果」 |
| saving | 「正在保存画像」 |
| done / finished | 「画像已保存」；仅在正式保存成功后显示 |
| 运行中的操作 | 「取消」 |
| cancelling | 「正在停止任务，请稍候」 |
| cancelled | 「任务已取消，未保存本次结果」 |
| interrupted | 「上次任务因服务重启而中断，请重新生成」 |
| 失败 | 「本次生成未完成，请稍后重试」；有已保存画像时可补充「此前保存的画像仍可查看」 |
| 达到预算、无结果 | 「本次处理达到上限，未保存新画像。可缩小材料范围后重试。」 |
| 有限结果 | 「本次结果覆盖有限，未确认的内容已保留为未知。」 |
| 依据失效 | 「来源已不可用，请重新生成画像。」 |
| 书架说明（修正原有“仅攻略”文案） | 「生成画像或攻略时，系统检索启用资料中的相关原文片段。书中的观点单独标注，始终与人物发言分开。」 |
| 上传完成（沿用现有提示位置） | 「资料已入架，可以用于画像和攻略参考。」 |

不新增自动重试、通知、预计剩余时间、人工评分、确认向导或导出入口；重试使用已有生成/更新按钮。`phase=finished` 本身不能代替 `status=done` 证明已保存。

## 5. 范围边界与风险审阅

### 本轮保持

- 既有界面入口、词项检索、轮询、PostgreSQL 文档存储和已有 DSH/AgentScope 接入；必要兼容字段与最小任务记录。
- 两条画像路径都需实际工具观察后模型继续；证据、结构、修订、取消屏障不能为减少工作而省略。
- 无书允许有限画像，未命中不算服务故障；有冲突保留未知。本人身份仍由现有导入选择和材料标注确定，不引入全量身份系统。
- 已有策略保持可用；关系目标只影响建议，不用于改写人物事实。

### 不进入本轮

独立关系档案、向量库、重排、新服务/数据库/付费依赖、多 Agent、联网搜索、新 MCP、多轮聊天产品、摘要记忆、自动发消息、平台全历史订阅、云部署、监控平台、UI 重设计、Token 流/SSE。本文未新增建议项或把后续优化列为验收条件。

### 需 TL 协调的已承诺风险（不构成扩项授权）

| 编号 | 风险与影响 | 最小处理 / 报告条件 |
| --- | --- | --- |
| R01 | 书架及上传完成现文案只提攻略，画像接入后会误导用户 | 按第 4 节改现有两处文案即可，不新建页面 |
| R02 | 当前知识删除说明仅提攻略；新增画像知识引用含快照文本，可能在删除后仍显为有效 | 后端与前端对齐旧/新及历史画像依据失效；复用既有删除语义，A12 验证，不新增保留档案 |
