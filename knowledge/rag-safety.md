# RAG 检索安全规则（供 Agent 自查）

本地受控 RAG（V1）的检索必须遵守以下规则：

1. 只检索 `rebuild/knowledge/` 下显式纳入的非敏感文档；不访问网络、云服务或外部
   连接器。
2. 拒绝任何形式的路径越界：`../`、绝对路径、symlink 越界、隐藏文件（点开头）、
   环境变量引用、`.run/` 中的账号或凭证数据。
3. 每个检索结果必须包含 `sourceId`、标题、文件相对路径、片段与内容哈希；回答引
   用知识时必须返回 citation。
4. 知识不可用时必须明确标记 `EVIDENCE_MISSING`，不得凭空补全。
5. 索引可确定性重建，不依赖外部向量数据库；所有测试离线、可重复。
6. RAG 结果只提供研究证据，不能作为自动审批依据，也不能产生回测指标。
